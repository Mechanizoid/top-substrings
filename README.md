# Project: Sub Strings

Implementation of a method that accepts a string and an array of valid substrings, and then returns a hash listing each substring and how many times it was found in the string.

## Odin Project

This is my solution for [Project: Sub Strings](https://www.theodinproject.com/lessons/ruby-sub-strings) from the Ruby course at [The Odin Project](https://www.theodinproject.com).
